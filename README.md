# alarm-C
Utilizing my dog to wake me up in the morning, also just a small C practice project.

main idea: play a sound file with my voice, triggering my dog to come over and wake me up, thats basically it.

This code is probably written quite poorly, I am open to suggestions to be able to learn more. I have used SDL3 for playing audio, it is the simplest I could probably do and I may change things later on. It was a pretty fun and interesting project to learn a little bit of C.

Feel free to use this project as you please.
